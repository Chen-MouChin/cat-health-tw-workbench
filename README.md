# 貓健康站平板審稿程式

[貓健康站](https://chen-mouchin.github.io/cat-health-tw/)的小幫手用 iPad 審稿的程式。

網址：https://chen-mouchin.github.io/cat-health-tw-workbench/

- 這裡只有程式，沒有文章。文章由負責人做成審稿包交給小幫手，在平板上匯入。
- 文章和審稿紀錄只存在那台平板的瀏覽器，不會上傳。
- 程式在瀏覽器裡用 [Pyodide](https://pyodide.org/) 執行；第一次打開要有網路，之後沒網路也能用。

這個 repo 的內容由原始碼 repo 自動產生，請不要直接修改。
